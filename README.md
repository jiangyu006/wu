# 一片名为「我」的雪

一个手机优先的雪主题个人介绍网站。纯 HTML / CSS / JavaScript，无框架；除头像与网易云音乐外，无外部资源。

## 打开

- 直接双击 `index.html`。
- 手机浏览最佳比例约 390 × 844；桌面端会自动显示为居中的手机画框。
- 也可以用任意静态服务器托管整个文件夹。

## 三个界面

1. **序章**：飘雪、飘出的问句、`捧起她 / 不要`。点“不要”会依次进入四种雪的状态：融化 → 结霜 → 起风 → 雪停。
2. **对话**：微信单人聊天样式，备注“無”。無的头像是 `assets/wu-avatar.jpg`，用户头像是一枚雪花。
3. **我的世界**：标题「抓住我這一片雪花」，下一行右侧是“标题来自素雪-花序”（“花序”可点）。
   标题下加入小诗，前两行左对齐、后两行右对齐：
   > 我很喜欢雪 / 但不喜欢雪落下 / … / 因为落下了 / 我就抓不住了

   五个分类：**飞雪·关于我的**、**落雪·我的需知**、**瑞雪·我的喜点**、**寒雪·我的雷点**、**观雪·我和你的**。

## 观雪与音乐

- 观雪内有 6 个纸质卡片链接，按顺序：
  板评 → 小卡 → 板卡 → 印象收集 → 花序专栏[板评] → 花序专栏[小卡]。
- “我和花序的悄悄话”是超链接，指向 `和花序的悄悄话`（`ctGHxxQcrO7J`）；标题下的“花序”指向 `@花序`（`ce26hxkK2ndY`）。
- 观雪底部保留了完整的结尾文字（原“雪最后的话”），来源为「From零度诗-殁」。
- 页面右上角“雨夹雪-Seto”是音乐开关：点击播放/暂停网易云音乐《雨夹雪》- Seto。
  打开页面时会尝试自动播放；如果被浏览器拦截有声自动播放，会在第一次点击/触摸页面时自动补播。
  音频地址来自 `music.163.com`，需要联网；如果播放失败，页脚有“网易云 · 雨夹雪-Seto”链接可以跳转收听。

## 文件结构

```text
snow-me/
├── index.html          # 三个界面的结构与全部文案

├── assets/
│   └── wu-avatar.jpg   # 聊天里“無”的头像（来自 1.docx 的“头.jpg”）
├── preview/            # 预览截图
└── README.md
```

## 常见修改

| 想改什么 | 改哪里 |
| --- | --- |
| 名字“無”、标题「抓住我這一片雪花」 | `index.html` 的 `.world-name`、`.world-title` |
| 标题来源那行、花序链接 | `index.html` 的 `.world-credit` |
| 小诗 | `index.html` 的 `.world-poem` |
| 五个分类的文案 | `index.html` 中 `.panel[data-panel="feixue/luoxue/ruixue/hanxue/guanxue"]` |
| 六个金山文档链接 | `index.html` 中 `.paper-stack` 内 6 个 `<a href="...">` |
| “我和花序的悄悄话”链接 | `index.html` 的 `.paper-caption` 内 `<a>` |
| 聊天台词 | `app.js` 的 `say("你终于来见我了吗")`、`say("靠近我感受我的温度吧")` |
| 点“不要”的四段文案 | `app.js` 的 `NO_STATES` 与 `HINTS` |
| 头像 | 替换 `assets/wu-avatar.jpg`；用户雪花头像在 `app.js` 的 `USER_FLAKE` |
| 音乐 | `index.html` 的 `<audio id="bgm">` 与 `#music-toggle`；歌曲页链接在页脚 |
| 配色、字体、留白 | `style.css` 顶部的 `:root` 变量 |

## 说明

- 雪花、图标、聊天气泡、纸质卡片全部用 CSS / Canvas / 内联 SVG 绘制；除头像和音乐外没有外部依赖。
- 对话是前端脚本，没有后端；刷新页面或点“重新看雪”即可从头体验。
- 音乐播放需要网络，且受网易云版权/地区限制；播放失败时会提示走页脚链接。
- 支持 Chrome / Edge / Safari 现代版本；已处理 `prefers-reduced-motion`。
- 部署：把整个 `snow-me` 文件夹上传到 GitHub Pages、Netlify、Vercel 等静态托管即可，无需构建。
